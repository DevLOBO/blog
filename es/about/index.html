Acerca de

🚀 Proyectos y Logros Relevantes

🧠 Optimización de rendimiento:

Reduje el tiempo de ejecución de una consulta en Oracle Database de 30 a 5 minutos mediante la indexación estratégica de columnas utilizadas en cláusulas GROUP BY, ORDER BY y WHERE. Además, implementé procesamiento paralelo utilizando la funcionalidad PARALLEL de Oracle para maximizar el rendimiento del sistema.

🔄 Migración de arquitecturas:

Contribuí en la transición de una arquitectura monolítica hacia microservicios, comenzando con la migración de un sistema de alertas al usuario. Separé componentes clave y los desplegué como microservicios en WebLogic, reutilizando eficientemente lógica existente en PL/SQL.

🤖 Automatización:

Desarrollé un script en Python que automatiza la configuración inicial de nuevos API Proxies en Apigee, generando archivos XML con políticas estándar listas para ser desplegadas, reduciendo significativamente el tiempo de configuración manual.

Implementé un script adicional en Python para la generación automatizada de reportes a partir de múltiples fuentes internas (bases de datos, servicios y aplicaciones), reemplazando un proceso basado en PowerQuery. Esta automatización redujo el tiempo de generación de reportes de 5 minutos a menos de 1 minuto.

📊 Monitoreo proactivo:

Diseñé e implementé un microservicio que monitorea periódicamente los códigos de respuesta de los API Proxies en Apigee, detectando automáticamente caídas o errores frecuentes en los servicios internos y notificando a los equipos responsables para una resolución proactiva.

🌐 Creación de página web personal con IA:

Diseñé una página web personal con funcionalidades impulsadas por inteligencia artificial para automatizar la redacción de artículos, traducción multilingüe y despliegue continuo del sitio.
