## 🚀 Proyectos y Logros Relevantes

<details>
  <summary>🧠 <strong>Optimización de rendimiento:</strong></summary>
  <p>Reduje el tiempo de ejecución de una consulta en Oracle Database de 30 a 5 minutos mediante la indexación estratégica de columnas utilizadas en cláusulas <code>GROUP BY</code>, <code>ORDER BY</code> y <code>WHERE</code>. Además, implementé procesamiento paralelo utilizando la funcionalidad <code>PARALLEL</code> de Oracle para maximizar el rendimiento del sistema.</p>
</details>

<details>
  <summary>🔄 <strong>Migración de arquitecturas:</strong></summary>
  <p>Contribuí en la transición de una arquitectura monolítica hacia microservicios, comenzando con la migración de un sistema de alertas al usuario. Separé componentes clave y los desplegué como microservicios en WebLogic, reutilizando eficientemente lógica existente en PL/SQL.</p>
</details>

<details>
  <summary>🤖 <strong>Automatización:</strong></summary>
  <p>Desarrollé un script en Python que automatiza la configuración inicial de nuevos API Proxies en Apigee, generando archivos XML con políticas estándar listas para ser desplegadas, reduciendo significativamente el tiempo de configuración manual.</p>
  <p>Implementé un script adicional en Python para la generación automatizada de reportes a partir de múltiples fuentes internas (bases de datos, servicios y aplicaciones), reemplazando un proceso basado en PowerQuery. Esta automatización redujo el tiempo de generación de reportes de 5 minutos a menos de 1 minuto.</p>
</details>

<details>
